# 💬 AI Infinity Dialog

[![Made with pollinations.ai](https://raw.githubusercontent.com/pollinations/pollinations/main/packages/ui/src/brand/badge-made-with.svg)](https://pollinations.ai/?ref=badge)

**AI Infinity Dialog** is an autonomous multi-agent simulation web application built for **POLLEN-QUEST #19178** where two AI personas converse endlessly in real time with dynamic voice synthesis powered by **Pollinations.ai**.

## 🌐 Live Web App
- **Live Demo:** [https://lekezoa.github.io/pollinations-ai-infinity-dialog/](https://lekezoa.github.io/pollinations-ai-infinity-dialog/)

## 🚀 Features
- **Hilarious Scenarios:**
  - 👔 *The Endless Job Interview* (inspired by the viral Reddit post where neither AI knows how to hang up).
  - 🛸 *Conspiracy Theorist AI vs Ultra-Pedantic Fact-Checker*.
  - ⏳ *Victorian Time Traveler (1820s) vs Hyperactive Crypto Tech Bro*.
  - 🤖 *Optimistic Smart Toaster vs Nihilist Android*.
- **Integrated Voice Synthesis:** Each autonomous conversational turn can be spoken aloud in real-time.
- **Autonomous Multi-Turn Loop:** Agents listen, respond, and adapt their personas continuously.
- **Bring Your Own Pollen (BYOP):** Integrated API key support for users to power conversation with their own balance.

## 🛠️ Built With
- **Pollinations.ai API:** `https://gen.pollinations.ai/v1/chat/completions`
